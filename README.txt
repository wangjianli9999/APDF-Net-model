APDF-NET: SUPPLEMENTARY INFERENCE PACKAGE

1. PURPOSE AND REQUIRED FILES

This package estimates leaf nitrogen content (LNC, %) from prepared four-band
TIFF images using frozen Attention-TDAE and APDF-Net models. It needs no
external project scripts, training data or measured labels for inference.

Keep the following layout:
  test.py                         Complete feature extraction/inference code
  args.yaml                       Input, model and output path configuration
  README.txt                      These English instructions
  requirements-inference.txt      Pinned direct Python dependencies
  attention_tdae_weights_5D.pth Attention-TDAE checkpoint: 47 inputs, 5 latent
  scaler_X.pkl                    Training scaler for 47 input features
  apdf_net_best.pth            APDF-Net checkpoint: 5 inputs, 1 output
  apdf_net_scaler.pkl          Training scaler for 5 latent features
  apdf_net_meta.json           APDF-Net feature order and input dimension
  test data/                      12 cropped TIFFs, numbered 1 through 12
  inference_results/
    predictions_summary.json      Reference output, regenerated by the test

The images are from the supplied 2024-04-10-13-20-14 acquisition folder.
The space in "test data" is intentional; preserve this package structure.

2. ENVIRONMENT AND INSTALLATION

Validated: Python 3.10.15 on Windows; NumPy 1.26.4, pandas 2.2.2,
PyTorch 2.7.1+cu118, scikit-learn 1.7.2, scikit-image 0.24.0, rasterio 1.3.10,
joblib 1.4.2, PyYAML 6.0.2. CPU inference needs no CUDA-capable GPU.
The requirements specify torch 2.7.1 without requiring a CUDA build.

In a Python 3.10 environment:
  python -m pip install -r requirements-inference.txt

Use the pinned scikit-learn version for the supplied scalers. Load only the
trusted supplied artifacts. Installation requires network access unless
packages are locally available. Tests used an existing environment; a fresh
installation and other operating systems have not been tested. Float32
roundoff may vary slightly across builds.

3. INPUT AND CONFIGURATION

Each TIFF must have exactly four bands in order 555 nm (green), 660 nm (red),
720 nm (red edge), 840 nm (near infrared). Use images with the same radiometric
preparation, registration, filtering, background removal and cropping as the
training data. Zero is background. This script starts at feature extraction
and performs none of those upstream image operations. It cannot infer band
wavelengths from pixels. RGB or raw camera DN images are unsuitable.

Default args.yaml:
  image: test data
  model_dir: .
  output_dir: inference_results

YAML paths are relative to the YAML file, or may be absolute. output_dir is a
directory, not a JSON filename. Set it to null for automatic directory naming.
Folder input selects spectral_bg_removed_cropped_<ID>.tif or .tiff files in
numerical ID order without recursion. Full-scene intermediate images are
excluded. Duplicate IDs and empty matching folders cause an error.

4. RUN

From this package directory:
  python test.py

The default run processes the 12 supplied images. The default args.yaml is
located beside test.py even when execution starts from another directory.

Overrides:
  python test.py --config /path/to/args.yaml
  python test.py --image "test data/spectral_bg_removed_cropped_1.tif" --output-dir single_result
  python test.py --image /path/to/folder --output-dir /path/to/results
  python test.py --model-dir /path/to/models

Command-line paths override YAML values and resolve from the terminal's
working directory. Select a different output directory for custom runs to
preserve the bundled reference output. Moving the package requires no change
to its default relative paths.

5. OUTPUT AND EXPECTED RESULTS

Only inference_results/predictions_summary.json is generated by default:
  [
    {
      "Image Name": "spectral_bg_removed_cropped_1.tif",
      "predicted_N_content": "4.452%"
    }
  ]

The full file has 12 records. Each estimate is a string with three decimals
and a percent sign. Predictions are already in percent; no multiplication by
100 is applied. No intermediate features or diagnostic files are saved.
Results are also printed. The final JSON is written after all images succeed,
replacing any previous result. On failure an older file may remain; check the
exit status. With output_dir: null, automatic paths are relative to test.py:
  folder: inference_results/<folder name>/predictions_summary.json
  image:  inference_results/<parent folder>/<image stem>/predictions_summary.json

Expected image ID : LNC (%):
   1 : 4.452%       2 : 4.760%       3 : 4.694%
   4 : 4.594%       5 : 4.628%       6 : 4.639%
   7 : 4.558%       8 : 4.511%       9 : 4.444%
  10 : 4.185%      11 : 3.947%      12 : 3.749%

6. METHOD

Image -> 32 textures + 15 vegetation indices -> scaler_X -> Attention-TDAE
encoder -> 5 latent features -> APDF-Net input scaler -> APDF-Net -> LNC (%).

Feature order is MEA, VAR, HOM, CON, DIS, ENT, ASM, Cor for each band in
wavelength order, then NDVI, GNDVI, NDRE, RVI1-RVI6, GRVI, DATT, MNDI, MTCI,
RERVI, RESR. Indices use unrounded band means over the shared mask where any
band is nonzero, not averages of pixelwise indices. Texture MEA/VAR use
positive pixels. Positive values are quantized per band to 1-63; non-positive
values remain zero. GLCMs are symmetric/normalized with distance 1 and angles
0, 45, 90, 135 degrees. Average the matrices before statistics. Background
level zero participates. HOM uses 1+abs(i-j); ASM uses sum(P**2).

Training CSV precision is preserved: non-VAR features round to four decimals,
then use .4e for nonzero magnitudes below 0.001, otherwise .4f. The original
float32 latent CSV round trip is reproduced in memory. These are numerical
compatibility steps, not saved process files. No resizing or clipping is added.

Checkpoints load strictly with weights_only=True. Both models use evaluation
mode, stored BatchNorm statistics and disabled dropout. CPU, one PyTorch
thread and deterministic operations are used. Models/scalers load once per
run without fitting or training. APDF-Net learned unscaled nitrogen content;
its prediction needs no inverse transform.

Invalid band counts, non-finite data, empty images, insufficient positive
pixels, undefined correlations, zero index denominators or incompatible
model dimensions cause errors rather than imputation.

7. VALIDATION AND LIMITS

Package checkpoints, scalers and all 12 images were compared with the original
supplied files. Validation covers the default batch, single-image overrides,
execution from another working directory, and relocating the package to a
separate directory. The numerical pipeline retains the previously validated
feature definitions and predictions. See Section 5 for reference outputs.

No measured nitrogen labels are included. The test demonstrates inference
reproduction; accuracy, uncertainty and generalization require measured
reference values and appropriate experimental validation.
